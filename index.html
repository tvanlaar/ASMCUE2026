Getting the Reads into Galaxy

Short-read Illumina sequencing files should be demultiplexed, with one set of files for each sample. Paired-end files should be labeled with R1 and R2 in their filenames. If your files are organized this way, they are ready to upload.

Once the reads are uploaded, select both files and choose Auto Build List to create a paired collection containing the forward and reverse reads.

Quality Assessment and Quality Control

Now that the reads are in Galaxy, use FastQC to investigate the overall quality of the sequencing reads.

We can examine the FastQC results either by downloading the file to the computer or within the Galaxy interface.

Info on how to interpret

Read Trimming with fastp

We can use fastp to preprocess the reads. Fastp can remove any areas with lots of Ns (representing poor sequencing quality), reads that are too short, adapter and primer regions, etc.

Once the reads have been trimmed, you will have the output reads and results files.

The results file is informative because it contains all the statistics of the number of reads, percent passing, and GC content that will be useful when writing your Methods section. After this, you can run FastQC again, this time on the trimmed reads.

Genome Assembly with SPAdes

You will be using SPAdes to assemble your reads. You should make sure to select your trimmed as the input for SPAdes so only the high quality reads are being assembled.
